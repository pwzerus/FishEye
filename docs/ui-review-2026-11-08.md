# UI review and bug hunt, 2026-11-08

Local only: backend on SQLite (`fishpilot_dev.db`, semantic search on, as
served), frontend `npm run dev`. Nothing committed or deployed.

How it was checked: every page opened in the app's browser and audited by
script (horizontal overflow at the viewport width, images without `alt`,
broken images, buttons and links without a name, inputs without a label,
duplicate ids, tap targets under 24 px, alerts on the page), then the main
journeys walked through by hand, the API exercised directly, and the code
read where something looked wrong.

Status: **fixed** (changed here, with a test where one fits), **not a bug**
(looked wrong, checked, is fine), **open** (needs a decision or more work).

## Walked through and working

Checked in a real (headless) Chrome at 1280×800 and 390×844, English and
Chinese, with billed map tiles blocked (MapTiler is paid per request; the map
fell back to OpenStreetMap raster tiles, as designed):

- Home, map, fish list and a fish page, what to buy, Ask, photo ID, rules
  (list and a state), sources, first trip, catches, sign in, account,
  privacy, 404: no horizontal overflow, no broken images, no unnamed
  buttons or unlabelled inputs, no console errors.
- Map: choosing Austin zooms in and loads lakes, shops and clusters; a lake
  opens its panel (entrances, fish, today's plan with the weather, shops
  nearby); a shop opens its popup.
- Ask (search only, no model call): a knot question, an off-topic question,
  a Chinese question, a lake question and an empty box all answer sensibly.
- Accounts: sign-up rejects a short password and a bad email with clear
  messages, then signs in with a welcome; sign out; a wrong password says so;
  signing in honours `?next=`. Admin: overview, feedback (and "Mark
  handled"), Ask misses.
- Feedback: the dialog sends and closes with a thank-you toast.
- Photo ID: a largemouth bass photo comes back Largemouth Bass, 97%; the
  gear camera returns candidates.
- Sharing a catch: pin, photo (the photo check picks the fish), date, title,
  notes, who can see it. Not submitted.

Left behind locally: a test account (admin in the dev database only, its
password in `F:\tmp\ui\test-account.txt`), two test feedback messages marked
handled, and a few Ask misses from the test questions.
